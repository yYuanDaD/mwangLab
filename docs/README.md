- [Merged Bo benchmark cases (2026-09-10)](reviews/BO_BENCHMARK_CASES_MERGED_20260910.md) — merged review of paper discrepancies and uncertain bulk, scRNA-seq, and proteomics cases; each case uses data link → paper link and extracted paper conclusion → Agent result → review status.

- [Uncertain cases analysis (archived)](reviews/UNCERTAIN_CASES_ANALYSIS_20260910.md)

- `assets/` — images referenced by documentation and implementation notes.
- `SEACDM_SCHEMA.md` — SEA-CDM schema reference.
- `PROJECT_STRUCTURE_AUDIT.md` — repository layout and cleanup audit.

The dated files in `status/` and `changelog/` are historical records. Start with
the root `README.md` for current setup and usage.
