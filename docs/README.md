# Documentation

Project documentation is grouped by purpose:

- `guides/` — workflow specifications, demo prompts, and pathway guides.
- `reviews/` — design reviews and migration notes.
- `status/` — dated project status snapshots.
- `assets/` — images referenced by documentation and implementation notes.
- `SEACDM_SCHEMA.md` — SEA-CDM schema reference.
- `PROJECT_STRUCTURE_AUDIT.md` — repository layout and cleanup audit.

The dated files in `status/` and `changelog/` are historical records. Start with
the root `README.md` for current setup and usage.
