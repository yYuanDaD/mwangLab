## How each paper will be run (after the limit resets)

Use the desktop app's bundled CLI (`%LOCALAPPDATA%/OpenAI/Codex/bin/<hash>/codex.exe`), one
paper at a time, with a 60-minute timeout:

```bash
codex exec --skip-git-repo-check --ephemeral --json --color never -s workspace-write -c sandbox_workspace_write.network_access=true -c model_reasoning_effort="medium" -C E:/agent/mwangLab_pdf -
```

Send the brief's request on stdin. Prefix it with one environment line: use
`.venv-pdf/Scripts/python.exe` and set `PYTHONIOENCODING=utf-8`.

Record wall time, and sum `usage` (`input_tokens`, `cached_input_tokens`, `output_tokens`) over
the `turn.completed` events. Then run `validate_decision_contract.py` on each run directory.
