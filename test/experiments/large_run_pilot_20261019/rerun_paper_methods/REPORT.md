# 照原文方法重跑 45 篇里"缺方法"的 8 篇

日期：2026-10-29。输入是 45 篇大跑存下的对齐后矩阵和元数据（`runs_claude/`），没有重新下载 GEO，没有调用任何 LLM API，全部在本机 R 4.6 上跑。

## 结论

- 缺的方法补上了 7 种：SVA、DESeq2 LRT、apeglm 收缩、edgeR QL+TMM、能配对和加协变量的 voom+TMM、混合效应 ANOVA+Tukey、老版 DESeq。代码在 `tools/r_de_tools.py` + `tools/r_de.R`，合成数据自测 `test/unit/test_r_de.py` 10 项全过。
- 照原文方法重跑后，4 篇基本对上原文数字：GSE140089（702 vs 706）、GSE159861（745/251/308/363 vs 744/251/294/326）、GSE208639（178 vs 176）、GSE283493（7/454/1/18 vs 7/353/2/14）。
- 1 篇明显靠近但还差一截：GSE179302 从 0 个到 344 个（原文 767），差的一块可能是 IHW，本机装不上。
- 2 篇照原文方法也对不上：GSE273041（混合效应 ANOVA）和 GSE293221（老版 DESeq）。两篇都缺原文的基因过滤或计数口径，方法本身不是主要原因。
- 1 篇没做：GSE279359（小鼠部分）要用 Swan，这是一个长读长转录本分析工具，不在这次补的范围里，GEO 上的文件也已被作者过滤过。

## GSE283493 的配对：组别 + 字母

论文写明两种脂肪取自同一批大鼠，GEO 没有动物编号。上次判断"没法配对"，检查的是"只用字母 a–f 当编号"。这次按复核的建议，把"组别 + 字母"当作动物编号（24 只鼠）并先用数据检验：

- 每个组织、每个组先减去组内平均，再比较皮下和内脏脂肪样本的残差相关。
- 组别 + 字母相同的样本对，平均相关 0.21；其他样本对 −0.04。打乱字母 5000 次的置换检验 p = 0.0002，四个组都一致。
- 只用字母（上次的检查方式）：0.04 对 −0.01，p = 0.075，看不出配对。

所以"组别 + 字母 = 同一只鼠"有数据支持。这一步写成了可复用的检查 `tools/pairing_check.py:check_pairing_key`，以后遇到"没有受试者列、但标签可能藏着配对"的情况可以先跑它。它只能支持某个编号，不能证明编号不对，所以结论仍要记成"假设配对"。

按这个假设重跑交互（voom，动物作随机区组）：显著基因从不配对时的 296 降到 103，组内相关 0.12。原文的 LRT（632）没有考虑配对，我们照原文跑出的 707 也是不配对的。配对后交互基因少了一大半，说明原文的交互结果里有一部分来自把同一只鼠的两个组织当成独立样本。

## 环境和限制

- R 4.6 新装：edgeR、sva、apeglm、ashr、lme4、lmerTest、emmeans；老版 DESeq 1.38 用 `scripts/install_deseq1.R` 安装（它唯一的 C 文件在 1.38 里没有被调用，去掉后按纯 R 安装，统计方法不变）。
- IHW 装不上：R 4.6 没有二进制包，从源码编译需要 Rtools。装 Rtools 后可以补跑 GSE179302。
- 新执行器还没有接进 case_runner 的路由规则，目前是 case 规格里写 `tool: tools.r_de_tools:run_r_de` 直接调用。
