# 四个待定问题，详细说明

每个问题先讲是什么，再讲在大规模运行里看到了什么，最后给按"做出结果"这个总目标的建议。

---

## 1. 阈值：原文写的规则和原文的数字对不上

**是什么。** 差异分析对每个基因都算一个 p 值，可以理解成"这个基因其实没变、只是碰巧看起来变了"的概率。一次检验约 2 万个基因，即使全都没变，按 p < 0.05 也会有约 1000 个碰巧过线。所以通常要做多重检验校正（BH 方法），得到 padj，也叫 FDR 或 q 值。padj < 0.05 的含义是：报出来的这批基因里，假阳性预计不超过 5%。原始 p 宽松，padj 严格。

**看到了什么。** 有两篇论文写的是 padj < 0.05，但它们报的基因数只有用原始 p < 0.05 才算得出来：

| 论文 | 按原文写的 padj | 按原始 p | 原文报的数 |
|---|---|---|---|
| GSE297318 | 2 / 59 | 300 / 578 | 302 / ~586 |
| GSE328094 | 106 / 4 | 464 / 296 | 486 / 270 |

另有几篇（GSE183150、GSE134698、GSE283250）按 padj 几乎没有显著基因，但效应方向和原文一致。这些都是样本少（每组 3–4 个）、校正后过不了线的情况。

**和"做出结果"的关系。** 这正是 10/16 待办里 1.2–1.4 那条"门槛逐步降低"的规则要解决的问题。建议把它落实成一个固定的、记进决策记录的阶梯，所有论文统一用，不再照搬原文：

1. 默认：padj < 0.05 且 |log2FC| > 1。
2. 没有显著基因时，逐步降 log2FC 门槛：1 → 0.5 → 0.25 → 0。
3. 降到 0 仍没有：改用原始 p < 0.05（不校正），结果标为"探索性"。
4. 原始 p 也没有：这个比较记为"无差异"，不再往下放宽。

每一步都写进 threshold 关口，报告里写明这篇最终停在哪一级。原文的阈值只作参考记录，偏离原文不再算问题。这样上面两篇会自动停在第 3 级，数字和原文一致，同时标明是未校正的结果。

---

## 2. 文章里有运动，但测序的样本里没有

**是什么。** 我们的筛选是按"文章"判断的：文章里描述了运动干预，就算运动研究。但一篇文章常常有好几个实验，只有一部分做了测序。

**看到了什么。** 两类情况：

- **测序的样本完全不涉及运动（6 篇，已在 design 关口拒绝）：** 例如 GSE295777 的游泳实验只测了心脏超声，测序的是另一组手术小鼠；GSE245048 的训练小鼠没测序，测序的是基因型对比。
- **体外"运动中介"实验（3 篇，已经跑了）：** 测序的是培养细胞，用"运动产生的物质"处理，例如甲酸盐（GSE294230）、鸢尾素（GSE282942）、运动肌肉的胞外囊泡（GSE326247）。它们和运动有关，但不是运动本身对组织的影响。

**建议。**

- 第一类：在筛选阶段就按 GEO series 再查一次。series 的样本信息里找不到运动分组的，直接排除，省掉一次运行。按 46 篇的经验，这能再筛掉约 6 篇。
- 第二类：按"做出结果"的目标，建议保留并照常分析，但单独标成"运动中介（体外）"一类，不和真正的运动对照混在一起统计。

## 3. 一个模型拟合全部样本，还是每两组单独拟合

**是什么。** 有 3 组以上时（比如对照、运动、运动+药物），比较"运动 vs 对照"有两种算法：

- **联合模型：** 用全部样本一起估计每个基因的波动大小（离散度），再从中取出这一对的比较。样本多，估计更稳，统计上更标准。
- **两组单独拟合：** 只拿这两组的样本来算。

两种方法的效应大小（log2FC）几乎一样，差别在显著性。如果别的组波动特别大，联合模型会变保守；反过来会更敏感。

**看到了什么。**

- 联合模型才对上原文的：GSE308674（480 vs 原文 474；单独拟合 328）、GSE164798（828 vs 835；单独拟合 3828）、GSE293221（32 vs 32；单独拟合 385）。
- 单独拟合才对上原文的：GSE275818（1308 vs 1347；联合 1482）、GSE301564（原文点名的基因只在单独拟合时全部显著）。

原文大多不写自己用的是哪种。

**建议。** 默认用联合模型，同时把两组单独拟合也跑一遍，结果都保存，主结果用联合模型。这样两种数字都在，审阅时能直接看出差别。如果原文明确写了单独拟合，主结果就跟原文。

## 4. voom + TMM 执行器

**是什么。** RNA-seq 的原始计数要先做"标准化"，消除每个样本测序深度不同的影响。最简单的方法是按总读数缩放（CPM）。TMM 更稳一些：它假设大多数基因没变，用这些基因来定缩放系数，不会被少数极高表达的基因带偏。voom 是 limma 处理计数数据的标准做法，通常和 TMM 一起用。

**看到了什么。** 现有的 voom 工具不做 TMM，也不能加协变量（比如 RNA 质量 RIN）。三篇论文用的正是 voom + TMM：GSE156724、GSE159861、GSE267763。最明显的是 GSE267763 的线粒体样本：线粒体 rRNA 占读数的 9–77%，不做 TMM 时 p 值全挤在 1 附近，一个基因都检测不出来；加上 TMM 后得到 0 vs 原文 0、全肌肉 32 vs 原文 34，对上了。这三篇目前都是子代理手动绕过的。

**建议。** 补上：给 voom 工具加 TMM 和协变量支持。工作量不大，代码里已经有 TMM 的计算函数。

## 总结：建议的下一步

| 问题 | 建议 |
|---|---|
| 1 阈值 | 实现统一的逐步放宽阶梯（padj+FC → 降 FC → 原始 p），替代照搬原文 |
| 2 没有运动样本 | 筛选按 series 再过滤一次；体外中介实验保留但单独分类 |
| 3 联合 vs 单独拟合 | 默认联合模型，单独拟合作为对照一起保存 |
| 4 voom + TMM | 补上执行器 |
