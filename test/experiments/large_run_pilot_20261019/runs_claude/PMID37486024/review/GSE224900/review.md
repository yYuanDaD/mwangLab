# GSE224900 复核结论

**总体: pass**(无 blocking / major 项)

该研究是卧床失用与恢复期(安慰剂 vs 二甲双胍)试验,没有运动训练臂,分析记录已明确说明。按受试者分块的配对模型与论文的 5% FDR 规则一致。

## 需关注项(minor)
- **threshold**:转录正确(padj<0.05,无 FC 阈值,S2.7.p1)。但恢复期论文计数 3550 / 1386 更接近 padj<0.05 且 |log2FC|>0.585 的结果(3252 / 1422),而实际应用规则给出 5764 / 2668。建议在 HANDBACK 或差异记录中补一句。
