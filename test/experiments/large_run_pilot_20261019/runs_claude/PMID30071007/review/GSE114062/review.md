## 不同意的项
- **pairing (major)**: 记录称"GEO 无动物 ID,未建模"。但 packet A 给出候选配对键(标题后缀,按品系内 0-3):连接 14/15 个样本,7 个键在两个脑区各出现一次且无重复;表达相关检查支持(同键 r=0.249,其他 -0.036,置换 p=0.001)。论文 S2.2.p1 称 16 个"individual mouse samples"(8 只小鼠 x 2 脑区),说明小脑和纹状体很可能来自同一只小鼠,但论文没有明说。脑区主效应和品系x脑区交互作用(论文的 86 个基因,本次 75 个)受未建模重复测量影响。
  - 修正: 保留与论文一致的主记录,另增一次标注为"假设"的敏感性分析,把标题后缀(品系内)作为动物项(7 对加 1 个未配对样本);把停止理由改为"动物 ID 未上传,候选键为标题后缀";向作者或 S1 File 确认。
