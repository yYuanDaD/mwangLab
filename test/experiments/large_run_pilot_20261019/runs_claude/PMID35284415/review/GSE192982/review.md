  - 若人工认为算:可直接分析。对已存的 log2-TMM 矩阵用 limma,`cond` 以 Static 为参照,按 donor 做区组(n=8/组),阈值 FC>2 且 q<0.05,与论文 CHP 236、SMG 388 个 DEG 比较。
